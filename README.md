# ЯЧУМА — десктоп

Отдельная сборка игры для браузера и десктопа. Telegram-версия живёт в другом репозитории и этим репо не затрагивается.

## Что здесь

| файл | что это |
|---|---|
| `index.html` | вся игра + HD-скин внутри (стили, слой и шрифты вшиты в файл) |
| `manifest.json` | PWA-манифест |
| `sw.js` | service worker, кэш `yachuma-desktop-v1` |
| `icon-512.png` | иконка, тот же файл что в ТГ-версии (sha256 совпал) |
| `privacy.html`, `privacy-google.html`, `terms.html`, `LICENSE` | юридическое |

## Музыка

`music.mp3` в игре прописан, но его нет и в ТГ-репо — там он тоже отдаёт 404 и ни на что не влияет. Если музыка нужна, положи файл с именем `music.mp3` в корень.

## Как включается HD

- корень сайта — сразу десктоп-версия, редиректа на `landing.html` нет;
- `?hd=1` тоже работает — ссылка для проверок осталась прежней.

## Деплой

Заливается один `index.html`. Отдельных `hd.css` / `hd.js` / файлов шрифтов нет — всё внутри, поэтому кэш не может отдать стили от одной версии к разметке другой.

После заливки — очистить кэш CDN (Cloudflare → Purge Everything).

## Что делает HD-слой

Только **читает** состояние игры (CSS-переменные `--lost`, `--bcfill`, классы) и рисует поверх. Игровые функции не вызываются, механика и баланс не тронуты.

- процедурная планета на canvas внутри `#battleCircle`: океан, суша, облака, полярные шапки, терминатор, блик, атмосфера; тонируется по `--bcfill`;
- космический фон со звёздами и спорами;
- вёрстка по макету: узкая шапка, ЭПИДЕМИЯ слева, ЯЧУМА по центру, «заражено» справа; плашки событий в одну строку; над Матёростью — Фатальность и Возраст чумы; боковые панели ЗАРАЖЕНИЕ / КОЛОНИЯ; HP-бар; МОР / СКРЫТЬСЯ; нижняя навигация;
- раскладка в `vh`, ширина `min(100vw,160vh)` — пропорции держатся на 2560×1440, 1920×1080, 1600×1000, 1440×900, 1366×768.

## Производительность

Буфер планеты ≤460 px, DPR ≤1.75. Планета перерисовывается ~9 fps и мгновенно при смене уровня или сектора потерь, космос — 30 fps, при скрытой вкладке всё останавливается. Замеры: 60 fps на 1920×1080, 55 fps на 2560×1440.
